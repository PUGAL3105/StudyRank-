## 🗄️ DATABASE SCHEMA

### Core Tables

#### `users`
- User account management
- Roles: student, teacher, admin
- Password hashing with bcrypt
- Timestamps for auditing

#### `books`
- Educational textbooks
- Class, subject, author tracking
- Uploaded by teacher (foreign key)
- Unique constraint on title/class/subject

#### `chapters`
- Book chapters
- Sequential ordering
- Optional content storage
- Cascade delete on book deletion

#### `questions`
- Student questions
- Links to book, chapter, student
- Supports image upload
- Timestamp tracking

#### `answers`
- AI-generated answers
- Key points as array
- Source page reference
- Diagram and video URLs
- Generated by AI flag

#### `quizzes` & `quiz_questions`
- Post-lesson quizzes
- Multiple choice questions
- Correct answer with explanation
- Sequential ordering

#### `quiz_attempts`
- Student quiz attempts
- JSON storage for answers
- Score calculation
- Timestamp for progress tracking

#### `progress`
- Learning analytics per student
- Counters: questions, lessons, videos, quiz attempts
- Average quiz score
- Last activity tracking

#### Additional Tables
- `book_chunks` - For RAG embeddings (Phase 3)
- `saved_items` - Bookmarking answers
- `feedback` - Student feedback

### Database Indexes
- All foreign keys indexed
- Search fields indexed (email, class, subject)
- Performance optimized for production

## 🔌 API ENDPOINTS (Phase 1)

### Authentication
- `POST /api/auth/register` - Create account
- `POST /api/auth/login` - Login
- `POST /api/auth/logout` - Logout
- `GET /api/auth/me` - Current user profile

### Books
- `GET /api/books` - List all books
- `GET /api/books/:id` - Get book details
- `GET /api/books/:id/chapters` - Get chapters
- `POST /api/books` - Upload textbook (teacher only)

### Questions
- `POST /api/questions` - Ask question (student only)
- `GET /api/questions/history` - Question history (student only)
- `GET /api/questions/:id/answer` - Get answer with source

### Response Format
All endpoints return structured JSON:
```json
{
  "success": true,
  "data": { ... },
  "message": "Operation successful",
  "error": "Error message if failed"
}
```

## 🚀 HOW TO RUN LOCALLY

### Quick Start (3 Terminal Windows)

**Terminal 1: Backend**
```bash
cd eduvision-ai/backend
npm install
npm run dev
# Runs on http://localhost:5000
```

**Terminal 2: Frontend**
```bash
cd eduvision-ai/frontend
npm install
npm run dev
# Runs on http://localhost:5173
```

**Database:**
```bash
# Install PostgreSQL if not already installed
# Create database:
createdb eduvision_ai

# Connection string:
postgresql://postgres:password@localhost:5432/eduvision_ai
```

### Environment Setup
```bash
cd eduvision-ai
cp .env.example .env
# Edit .env with your database credentials
```

- Framework code, not over-engineered
- Real-world patterns
- Enterprise-grade when needed
- Simple when possible
